Overview

A real-time system in the Overcooked environment where deep models infer a human collaborator's mental state from multimodal physiological signals (EEG, ECG, eye-tracking), and reinforcement-learning agents adapt their skills in response. Streaming infrastructure and containerized services keep the human-in-the-loop pipeline low-latency, and agent actions come with interpretable explanations.

What I built

  • Integrated Overcooked-AI with adaptive reinforcement-learning agents (hierarchical skill learning).
  • Connected physiological state-prediction models (EEG/ECG/eye-tracking) to the agent decision pipeline.
  • Enabled agents to adapt skill selection based on inferred human state, in simulation and human-in-the-loop deployments.
  • Built streaming (LSL) + containerized (Docker) services with FastAPI APIs for real-time operation.
  • Added interpretable explanations for agent actions.
