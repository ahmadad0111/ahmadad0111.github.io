Overview

An end-to-end hardware/software project: a pipelined MIPS processor and low-area computer-vision accelerators designed in Verilog, validated on a Xilinx Virtex-5 FPGA, with a supporting Java assembler that translates assembly into machine code. The work analyzes latency, area, and throughput trade-offs between general-purpose processing and dedicated vision accelerators.

What I built

  • Designed and implemented a pipelined MIPS processor in Verilog HDL.
  • Built low-area, high-performance computer-vision hardware accelerators.
  • Validated the full design on Xilinx Virtex-5 FPGA hardware.
  • Developed a Java assembler to translate assembly instructions into machine code, enabling hardware–software co-design.
  • Compared processor vs accelerator approaches on throughput-to-area ratio.
