Overview

A real-time conversational system that gives a SoftBank Pepper humanoid robot natural spoken interaction by connecting it to GPT-based language models through an API-driven architecture. Built for public-facing campus demonstrations, it pipes speech input to cloud inference and back to the robot with low latency.

What I built

  • Integrated the SoftBank Pepper robot with GPT-based conversational APIs.
  • Designed an API-driven architecture linking speech input, cloud inference, and robotic responses.
  • Built middleware for low-latency communication between the robot hardware and AI services.
  • Deployed for live, interactive public demonstrations.
