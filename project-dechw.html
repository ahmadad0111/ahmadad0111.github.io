Overview

DecHW tackles decentralized federated learning, where clients collaborate directly over peer-to-peer networks with no central parameter server. Under statistically heterogeneous (non-IID) data, naïve averaging converges slowly; DecHW uses second-order (Hessian) information to weight each neighbour's parameters by importance during aggregation, improving convergence and cutting communication rounds.

What I built

  • Built a PyTorch decentralized-FL training framework for peer-to-peer model exchange over graph-based communication topologies.
  • Developed DecHW, a Hessian-based aggregation method that weights parameters by second-order importance.
  • Evaluated on benchmark computer-vision datasets across heterogeneous network topologies and non-IID splits.
  • Benchmarked against FedAvg-style baselines, showing faster convergence and reduced communication overhead.
